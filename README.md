# Orthese Preview (`orthese.com` Static Site)

Public static GitHub Pages preview of the **Orthese** landing page (with interactive Composer Panel & 13-provider / 44-model selector), **Orthese Router** (`/router`), and **Marketplace** (`/marketplace`) storefront.

- **Live Preview:** https://lukag712.github.io/orthese-site/
- **Orthese Router:** https://lukag712.github.io/orthese-site/router/
- **Marketplace:** https://lukag712.github.io/orthese-site/marketplace/

## Local Development

```bash
pnpm install
pnpm dev
```

## Static Export

```bash
pnpm typecheck
pnpm build
# Generates static HTML/CSS/JS bundle in ./out/
```
