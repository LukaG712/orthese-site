01 · Getting Started

Quickstart

Orthese compiles from one Rust + GPUI core to both a zero-install WebAssembly browser dashboard and a native 120fps Desktop binary. Pick your target runtime and package manager below:

WebAssembly Sandbox (Zero-Install)
Standard scopes · Cloudflare Edge
Bashterminal · pnpm (Web WASM)
# Create a new WASM-compatible Piece
pnpm create orthese-piece my-piece --target wasm32
cd my-piece

# Install dependencies & launch local WASM canvas
pnpm install
pnpm dev:wasm

Scaffolds a standard Piece with zero elevated permissions and runs the wasm32 preview canvas locally.

03 · SDK & Manifest

Piece SDK (piece.json)

Every Piece declares its capabilities, accepted/emitted context contracts, default real model, and optional tokenRevShare in a single manifest. Free Pieces with tokenRevShare: true earn 20% of token margin automatically.

extends: "orthese.base-harness"

Inherits streaming, checkpoints, model switching, and SKILL.md loading.

permissions.elevated: []

Leaving elevated empty unlocks instant zero-install WebAssembly execution.

monetization.tokenRevShare

Keep community Pieces free while earning Polar creator attribution.

04 · Inter-Piece Piping

Shared Context Bus

Pieces never force copy-pasting between tabs. Any Piece emitting a typed contract publishes directly onto bus://workspace.default so downstream panes receive structured state immediately:

orthese/spec

Structured architecture & UI specs drafted by AI Prompt Box.

orthese/html-bundle

Live previewable HTML/Tailwind artifacts rendered in Website Builder.

orthese/git-diff

Folder-scoped patches & test reports verified in Software Engineer.

05 · Context Efficiency

Progressive SKILL.md

Skills stay indexed as lightweight frontmatter metadata and stream their full instruction body into the active context window only when triggered, keeping token usage lean.
