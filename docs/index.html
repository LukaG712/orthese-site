SDK & Manifest

Piece SDK (piece.json)

Every Piece declares its capabilities, accepted/emitted context contracts, default real model, and optional tokenRevShare in a single manifest. Free Pieces with tokenRevShare: true earn 20% of token margin automatically.

JSONpiece.json
{
  "id": "orthese.website-builder",
  "version": "0.1.0",
  "extends": "orthese.base-harness",
  "defaultModel": "gemini-4-neon",
  "permissions": {
    "standard": ["ai:generate", "context:send", "context:receive"],
    "elevated": []
  },
  "context": {
    "accepts": ["orthese/spec", "text/markdown"],
    "emits": ["orthese/html-bundle"]
  },
  "monetization": {
    "purchaseType": "free",
    "priceUsd": 0,
    "tokenRevShare": true
  }
}

Shared Context Bus

Pieces never force copy-pasting between tabs. Any Piece emitting a typed contract publishes directly onto bus://workspace.default so downstream panes receive structured state immediately:

orthese/spec

Structured architecture & UI specs drafted by AI Prompt Box.

orthese/html-bundle

Live previewable HTML/Tailwind artifacts rendered in Website Builder.

orthese/git-diff

Folder-scoped patches & test reports verified in Software Engineer.

Context Efficiency

Progressive SKILL.md

Skills stay indexed as lightweight frontmatter metadata and stream their full instruction body into the active context window only when triggered—keeping token usage lean.

Markdownskills/landing-page-architect/SKILL.md
---
name: landing-page-architect
description: Minimalist dark obsidian landing pages with tabular metrics
triggers: ["landing page", "hero", "marketing site"]
---

# Landing Page Architect

1. Start from an optically centered full-viewport hero on #121212.
2. Keep copy concise; pair every interactive widget with hairline borders.
3. Emit valid orthese/html-bundle payloads directly onto the Shared Context Bus.
Security & Tooling

Scoped MCP Hub & Tiered Permissions

Configure local stdio or remote Streamable HTTP MCP servers once in the workspace hub with per-Piece allowlists. Standard scopes (ai:generate, context:*) run safely in WebAssembly; elevated scopes (fs:write, shell:exec, local stdio MCP) prompt with click-to-approve diff guardrails on Desktop.
